AWS Multi-Tier Application

A segmented AWS environment for a FastAPI application, with private compute and managed data services.

AWSFastAPIPostgreSQL
Explore the project ↗

Business problem

Host and verify an API with separated network tiers, controlled service access, and scalable compute.

Architecture

Public ALB → private EC2 / FastAPI → RDS and S3. Secrets Manager supplies secrets; Systems Manager provides instance access.

Key decisions

Private compute reduces direct exposure. An ALB provides a stable entry point and health checks. AMI-based Auto Scaling reuses the configured application environment.

Implementation & verification

Verified health/version endpoints, S3 writes, IAM-authorized secret retrieval, and healthy ALB targets. Audited and decommissioned resources after testing.

Production: add infrastructure as code, HTTPS, database resilience, and automated delivery.
